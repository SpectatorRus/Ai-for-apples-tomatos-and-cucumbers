# Идея и Применение 
Данный проект создан с целью упрощения подсчёта яблок, помидоров и огурцов на фото для более быстрого подсчёта литров компота и банок солений.

В качестве модели-детектора была выбрана yolo11s из за стабильности и хороших результатов в тестах. Модель была обучена на 100 эпохах.


# Установка и запуск (Windows)
Создайте .venv c помощью командной строки(cmd) или PowerShell в папке вашего проекта

```bash
python -m venv .venv
```

Или если у вас несколько версий Python:

```bash
python3 -m venv .venv
```
------
Активируйте окружение
 
В командной строке (cmd):
```bash
.venv\Scripts\activate.bat
```
В PowerShell:
```bash
.venv\Scripts\Activate.ps1
```

-----
Склонируйте репозиторий и установите зависимости
```bash
git clone https://github.com/SpectatorRus/Ai-for-apples-tomatos-and-cucumbers.git
cd Ai-for-apples-tomatos-and-cucumbers
pip install -r requirements.txt
```

-----
Запустите app.py
```bash
python app.py
```

В проекте присутствует обученная модель(best.pt), но вы можете подключить свою изменив MODEL_PATH(11 строка) в app.py

# Немного про данные
В обучении использовалось 3833 аугментированных изображения. В которых:

|Class    |   Instances   |
|---------|---------------|
|apple    |  4877 (45.6%) |
|tomato   |  3293 (30.8%) |
|cucumber | 2556 (23.9%)  |

mAP50 test: 0.987 и mAP50 train: 0.995, разница 0,032 -> нет переобучения, но модель часто путает красные яблоки с помидорами

> Аугментировалось  917 реальных фото с аннотациями из 4627. В дальнейшем планируется разметить оставшиеся фото, что с аугментациями даст примерно **18550** фото. Все фото были сделаны вручную.
